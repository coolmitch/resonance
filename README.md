# 博辰 x 華碩智行：技術共振模擬器

An interactive visualization demonstrating technical collaboration resonance between Bocen (博辰) and ASUS Intelligent Cloud (華碩智行).

## Overview

This application uses wave physics principles to visualize how different collaboration frequencies between two organizations can create synergistic outcomes. When the frequencies align (resonate), the combined output is maximized.

## Features

- **Real-time wave visualization**: Three animated sine waves showing individual and combined outputs
- **Interactive frequency controls**: Adjust development/collaboration rhythms for both organizations
- **Phase synchronization**: Fine-tune alignment between the two waves
- **Resonance detection**: Visual indicator when frequencies are optimally aligned (< 0.2 Hz difference)
- **Collaboration efficiency analysis**: Real-time feedback on integration quality

## Usage

1. Open `resonance.html` in any modern web browser
2. Adjust the sliders to see how different frequencies affect collaboration outcomes:
   - **博辰研發頻率**: Bocen's R&D rhythm (1-10 Hz)
   - **華碩智行協作頻率**: ASUS collaboration rhythm (1-10 Hz)
   - **相位同步控制**: Phase synchronization control (0-100%)
3. Watch for the "共振狀態：最佳協作" indicator for optimal alignment

## Technical Stack

- React 18 (via CDN)
- Tailwind CSS (via CDN)
- HTML5 Canvas API
- Lucide Icons
- Babel Standalone (for in-browser JSX compilation)

## How It Works

The visualization represents:
- **Blue wave**: Bocen's development rhythm
- **Pink wave**: ASUS Intelligent Cloud's collaboration rhythm
- **Purple wave**: Combined research output (mathematical sum of both waves)

When frequencies align closely (resonance), the combined wave amplitude increases significantly, representing maximized collaborative output.

## No Build Required

This is a self-contained HTML file with no dependencies or build process. All libraries are loaded from CDNs.
